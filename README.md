# Marietta Dental Professionals — Homepage

A single-page static homepage built with plain HTML and CSS.

## Structure

```
index.html   # page markup and content
style.css    # all styling (colors, type, layout, responsive rules)
```

## Sections

- Hero with tagline and call-to-action
- About Marietta Dental Professionals
- Why Choose Us
- Services
- Mission & Vision
- Benefits
- Booking call-to-action
- Footer

## Running locally

No build step is required. Open `index.html` directly in a browser, or serve the folder with any static server, e.g.:

```bash
npx serve .
```

## Fonts

Uses Google Fonts (Fraunces for display headings, Work Sans for body text), loaded via CDN in `index.html`.
